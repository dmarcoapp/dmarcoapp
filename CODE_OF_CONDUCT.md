# Code of Conduct

DMARCo is a small project with a simple standard: be decent to the people you
are talking to.

- Assume good faith. Most confusion is a missing detail, not bad intent.
- Keep criticism about the code, the configuration or the report, never the
  person.
- No harassment, personal attacks, or unwelcome private contact.
- Respect that maintainers do this in their own time, and that "no" is a
  complete answer to a feature request.

This applies to issues, pull requests, discussions, commit messages and any
other space the project uses.

If someone is out of line, report it privately through
[GitHub](https://github.com/dmarcoapp/dmarcoapp/security/advisories/new) or by
mentioning it in a new issue if it is not sensitive. Maintainers may edit or
remove comments, close threads, or block accounts that do not follow this.
